# AI 음성 통화 시험하기 (이슈 #26)

OpenAI 실시간 음성(Realtime API)이 **우리 구조에서 정말 되는지** 작게 시험하는 안내서입니다.
서버가 임시 키를 주고, FE 가 그 키로 OpenAI 에 연결해 **AI 의 첫 인사가 들리면 성공**입니다.

> 이 문서의 아래쪽 **"시험 결과"** 칸은 시험을 해 본 사람이 채웁니다. 채우면 #26 의 완료 조건이 끝납니다.
> AI(Claude) 는 진짜 키도, 마이크도, OpenAI 계정 화면도 없어서 결과를 대신 적지 않았습니다.

---

## 1. 누가, 어디서

| 누구 | 하는 일 |
| ---- | ------- |
| BE 1명 | 배포 서버(Render)에 키를 넣고, 서버 로그를 봅니다 |
| FE 1명 | 통화 화면(FE#34)에서 통화를 걸고, 소리를 듣습니다 |

**어디서 — 배포 서버에서 합니다.** 이슈에는 "내 컴퓨터에서" 라고 적혀 있지만, 우리 팀은 GPT 키를 **배포 설정에만** 두기로 했습니다.
그래서 내 컴퓨터(`local`)에서는 통화가 항상 **503** 입니다. 키를 내 컴퓨터에 넣으려고 설정을 바꾸지 마세요. ([DEPLOY.md](./DEPLOY.md) "AI(GPT) 켜기")

> 이슈의 "OpenAI 키는 서버 `.env` 에만" 은 옛 문장입니다. 지금 BE 는 `.env` 를 쓰지 않고, Render 의 **Environment** 화면에만 넣습니다. (CLAUDE.md 3장)

## 2. 시험 전에 (꼭 이 순서로)

1. **OpenAI 계정에 월 사용 한도를 먼저 겁니다.** 음성은 분당 과금이라, 실수 하나로 돈이 크게 나갈 수 있습니다.
2. Render 의 **Environment** 에 두 값을 넣습니다. 자세한 것은 [DEPLOY.md](./DEPLOY.md) "AI 통화 켜기".
   - `OPENAI_API_KEY` — OpenAI 에서 받은 키. **이 화면에만** 입력합니다. 코드·문서·채팅·카톡 어디에도 적지 않습니다
   - `OPENAI_REALTIME_MODEL` — 음성 모델 이름. 시험에는 싼 `gpt-realtime-2.1-mini` 를 권합니다
3. 서버가 다시 켜지면 Render 로그에서 아래 줄이 보이는지 봅니다.
   ```
   [AI 통화] 켜져 있어요. (키와 음성 모델 이름이 설정돼 있습니다)
   ```
   `꺼져 있어요` 가 보이면 2번의 두 값 중 하나가 비어 있는 것입니다.

## 3. 시험 순서

1. FE 배포 주소에서 **로그인**합니다. (통화 API 는 로그인이 필요합니다)
2. 통화 화면에서 **통화 걸기**를 누릅니다. 브라우저가 **마이크 권한**을 물으면 허용합니다.
3. 이때 일어나는 일 (연결 순서):
   1. FE 가 서버에 `POST /api/v1/realtime/session` 을 부릅니다 → 서버가 OpenAI 에서 **임시 키**를 받아 돌려줍니다 ([API.md](./API.md) "AI 통화")
   2. FE 가 그 임시 키로 **OpenAI 에 직접** 연결합니다. 소리는 서버를 지나가지 않습니다
   3. 임시 키는 **60초 안에** 연결해야 쓸 수 있습니다
4. **AI 의 첫 인사가 들리면 성공**입니다. 한두 마디 대답해 봅니다.
5. 약 **1분** 뒤 통화를 끝냅니다. (통화 한 번은 최대 5분이고, FE 가 그 시간이 되면 끊습니다)
6. 1분 통화의 비용을 OpenAI 사용량 화면에서 확인합니다. 사용량은 바로 반영되지 않을 수 있어서, 조금 기다렸다가 봅니다.

### 3-1. 주변 소리 시험 (통화 수정 5)

서버는 임시 키를 만들 때 **잡음 줄이기(`near_field`)** 와 **말 차례 감지(`semantic_vad`, `eagerness: low`)** 를 함께 보냅니다. (`CallKeyClient`)
점검에서 주변 소리가 학생 말로 잡혀 통화가 엉뚱하게 흐른 적이 있어서 넣었습니다. 실제 소리로 아래를 확인합니다.

- [ ] 조용한 방에서 **아무 말 없이** 키보드 · 연필 · 의자 소리를 냈을 때 AI 가 끼어들지 않는가
- [ ] 옆 사람이 작게 이야기할 때 그 말이 내 자막(내 말)에 잡히지 않는가
- [ ] 학생이 **생각하느라 2 ~ 3초 멈췄을 때** AI 가 말을 끊고 들어오지 않는가
- [ ] 독서실처럼 **작게 말해도** 학생의 말을 놓치지 않는가
- [ ] AI 의 대답이 너무 늦게 시작되지 않는가 (`low` 는 최대 8초까지 기다릴 수 있습니다)
- [ ] 휴대폰을 귀에 댈 때, 이어폰을 낄 때, 스피커로 들을 때 각각 어떤가

결과가 나쁘면 `CallKeyClient` 의 상수(`NOISE_REDUCTION_TYPE`, `TURN_DETECTION_EAGERNESS` 등)를 바꿔 다시 시험합니다.

## 4. 막혔을 때

| 보이는 것 | 뜻 | 할 일 |
| --------- | -- | ----- |
| 통화 걸기 → **503** `"AI 통화가 아직 켜져 있지 않아요"` | 서버에 키나 음성 모델 이름이 없음 | 2번의 두 값, Render 로그의 `[AI 통화]` 줄 확인 |
| **503** `"AI 와 연결하지 못했어요..."` | 서버가 OpenAI 에서 임시 키를 못 받음 | Render 로그의 `[AI 통화] 임시 키를 받지 못했어요` 확인. 키·모델 이름이 맞는지, 월 한도에 걸리지 않았는지 |
| **429** `"오늘 통화는 다 썼어요..."` | 하루 한도(3번 · 15분)를 다 씀 (#33) | 다음 날(새벽 4시 뒤) 다시. 시험 중이면 한 사람이 너무 여러 번 걸지 않게 |
| **401** | 로그인이 안 됨 | 다시 로그인 |
| 연결은 됐는데 소리가 안 들림 | 마이크 · 스피커 권한, 브라우저 문제 | 마이크 권한 허용, 다른 브라우저로 |

## 5. 비용 어림값과 비교하기

[DEPLOY.md](./DEPLOY.md) 에 적어 둔 **어림값**은 이렇습니다. (2026-10-11 가격표, 1달러 1,400원)

- `gpt-realtime-2.1-mini`: 3분 통화 한 번에 약 70 ~ 90원
- `gpt-realtime-2.1`: 3분 통화 한 번에 약 210 ~ 240원

이 값은 "말하는 1분이 몇 토큰인지" 를 확인하지 못하고 계산한 것입니다. **시험에서 본 실제 값과 많이 다르면**
DEPLOY.md 의 표와 `AI_COST_WON_PER_CALL_MINUTE`(GPT 호출 기록의 분당 비용 어림값, 기본 80원)를 고쳐 주세요.
