# 과목별 공부와 성적 연결 (#48)

`GET /api/v1/insights/score-study`는 로그인한 사용자의 실제 점수가 2회 이상 있는 과목만 반환합니다.
미래 시험과 예상 점수는 제외합니다. 과목 번호 순, 시험 날짜·번호 순입니다.

- `sampleSize`: 실제 점수가 있는 시험 횟수. 5회 미만이면 `hypothesis: true`입니다. 5회 기준은 제품의 보수적인 표시 규칙이며 통계적 유의성 기준이 아닙니다.
- `exams[].scoreChange`: 같은 과목의 직전 실제 점수와 차이. 첫 시험은 `null`입니다.
- `exams[].days`: 시험 14일 전부터 전날까지 14개 날짜와 순공 분. 기록 없는 날은 0입니다.
- `studyMinutes`: 같은 과목의 공부만 더하고 일시정지를 뺀 뒤 분으로 반올림합니다. 날짜는 한국 새벽 4시 기준 시작일입니다. 날짜별 값도 해당 날짜의 밀리초를 합한 뒤 반올림하므로 날짜별 분의 합과 전체 분이 조금 다를 수 있습니다.
- `pointsPerStudyHour`: 점수 변화 ÷ 해당 시험 전 14일 순공 시간. 첫 시험이나 순공 0이면 `null`입니다.

공부와 점수의 관련성을 볼 참고 자료입니다. 시험 종류·난도가 달라질 수 있어 인과관계나 공부 효율의 확정 평가로 사용하면 안 됩니다.
모든 조회에 현재 사용자 번호를 넘기며 추가 테이블은 만들지 않습니다.
