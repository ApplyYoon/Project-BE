사용자가 막혔습니다: **$ARGUMENTS**

**고치기 전에 먼저 설명하세요.** 학생이 이유를 모른 채 고쳐지면 다음에 또 막힙니다.

## 순서

1. **무슨 일인지 확인** — 에러 메시지가 없으면 `./gradlew build` 를 돌려 직접 확인합니다.
   서버를 켜다가 난 에러라면 `./gradlew bootRun` 의 로그에서 `ERROR` 나 `Caused by:` 줄을 찾습니다.
2. **한국어로 번역** — 에러가 무슨 뜻인지 한 문장으로.
   예: "`cannot find symbol` → 그런 이름을 못 찾았다는 뜻이에요. 오타이거나 `import` 가 빠졌어요."
3. **왜 났는지** — 어느 파일 몇 번째 줄에서, 어떤 상황 때문인지 `파일:줄번호` 형태로.
   자바 에러는 길게 나옵니다. **맨 아래쪽 `Caused by:`** 와, 우리 코드(`com.ithopeschool.projectbe`)가 나오는 줄을 봅니다.
4. **어떻게 고칠지** — 방법을 말하고, 간단하면 바로 고칩니다.
5. **확인** — `/check` 로 검사를 돌려 진짜 해결됐는지 확인하고 보고합니다.

## 하지 않는 것

- 테스트를 지우거나 `@Disabled` 로 꺼서 넘어가기
- 빈 `catch` 로 에러를 삼키기
- 원인을 모른 채 라이브러리를 추가하기 (추가는 반드시 허락을 받습니다)

해결한 뒤 그 문서에 한 항목 추가하자고 제안하세요.
